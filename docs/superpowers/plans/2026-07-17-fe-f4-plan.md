# F4 — Library · Implementation Plan

Date: 2026-07-17 · Phase lead worktree: /Users/thomaskgould/dev/fe-f4 · Branch: fe/f4-library

## Goal
Rebuild the LIBRARY tab (phone canvas 5a, tablet canvas 2c master–detail 1fr/470px) as a
casebook-row browser + case detail, binding to the pinned `/api/v1/cases*` contract (B3
`avg_rating`/`run_count`/`done_for_you` + `open_count`/`done_count`). Implement the retired-done
rules (Design Decisions §0.4): type chips + Everything/Not done/Done toggles + "N OPEN · N DONE"
live count; open rows first, retired rows greyed below a "DONE — YOURS TO INTERVIEW WITH" divider;
detail flips CTA to "Case someone with this" and shows a faint "Get re-cased anyway — won't count
toward diagnostics". Detail: rating+runs aggregate, your history, case-pack PDF row ("It knows.").

## Architecture
- **Networking** (`ios/CaseRoom/Networking/`): extend `CaseSummary`/`CaseDetail` Codable with
  B3 aggregates; new `LibraryPage` wrapper carrying `open_count`/`done_count`; a new `LibraryService`
  protocol gains `library(query:) -> LibraryPage`. `sessions(scope:"recent")` (exists) feeds history.
- **View model** (`ios/CaseRoom/State/LibraryViewModel.swift`, new): fetches the page, maps API
  rows → `LibraryCase` (view type with derived kicker/meta/ordinal + optional decorations),
  applies the type-chip + done-toggle filters (done partition from `done_for_you`), builds the
  divider + counts, tracks tablet selection. `CasesViewModel` is retired/replaced.
- **Views** (`ios/CaseRoom/Views/`): `CasesListView` rewritten to canvas 5a (phone) with a
  `NavigationStack(path: AppRouter.shared.libraryPath)` and an iPad size-class branch to the 2c
  master–detail. `CaseDetailContent` (new, shared) renders the detail body; `CaseDetailView`
  (rewritten) is the phone push wrapper (loads + hosts content); the tablet right pane hosts the
  same content for the selected row.
- **Fixtures** (DEBUG only): a `-LibraryFixtures` launch arg injects a stub `LibraryService`
  (library + caseDetail + recentSessions) seeded with the Decisions §3/§7 canonical 8 cases (tablet `CASES`
  array) so screenshots render the retired divider / tags / RECOMMENDED states. Live screens bind
  to `APIClient.shared`. Mirrors F1's `-DevLogin` + `PreviewProfileService` precedent.

## Plan-review round 1 — resolutions (applied below)
1. **Meta field.** `difficulty` is the word form (Easy/Medium/Hard); `difficulty_score` is a float
   (e.g. 3.0). Row meta = `"D<Int(difficulty_score)>"` (fallback to the difficulty word if score
   nil); the `~25 min` duration is NOT in `/api/v1/cases` → omitted, documented as a seam. The
   `"rated by N candidates"` string is DETAIL-ONLY (never on the row).
2. **Count line = client-filtered.** `countLine` is computed from the CURRENT type+done-filtered
   rows (matches the canvas `libCount`: under "Done" → "0 OPEN · N DONE"), NOT from the page's
   type-only `open_count`/`done_count`. Page counts still validate Task 1 decoding.
3. **Phone-detail chrome.** A pushed `.caseDetail` must NOT show the shell's WordmarkChip / AvatarPill
   / tab bar (canvas 5a detail shows only a plain `‹ Library` 13/600 ink text + detail tag, no tab
   bar). RootShell (F1 deferred tab-stack mounting to F4) gets a MINIMAL additive change: bind the
   library `NavigationStack(path: $router.libraryPath)` and suppress the top pills + tab bar when the
   active tab is `.library` AND `libraryPath` is non-empty. Scoped so other tabs are unaffected;
   documented as an expected F1-deferral consumption for the orchestrator. Back control = plain ink
   text `‹ Library` (NOT glass BackPill, NOT underlined).
4. **Compile order.** Task 1 adds `library()` to APIClient only (no protocol churn). Task 2 defines a
   NEW `protocol LibraryService { library; caseDetail; recentSessions }` + `extension APIClient:
   LibraryService {}` in `LibraryViewModel.swift` (coexists with the old `CasesService`; nothing
   deleted). Task 3 rewrites `CasesListView` onto `LibraryViewModel` (old `CasesViewModel.swift`
   stays — `CaseDetailView` still references it). Task 4 migrates `CaseDetailView` onto
   `LibraryService`, THEN deletes `CasesViewModel.swift` (last reference gone). Every task compiles.
5. **Re-cased copy.** Canvas 5a renders only the button `Get re-cased anyway`. §0.4 adds the lowercase
   qualifier `won't count toward diagnostics`; render the button + a faint caption with that EXACT
   lowercase text, attributed to §0.4 (not the canvas).
6. **History score.** `SessionSummary` carries only `grade`+`role` (no per-case rating-received, no
   `case_id`). Matched-session line = `"<MMM dd> · <other_user>"` + (grade != nil ? `"<grade> avg"` :
   ""); no reference to a "given rating" field. Title-match + missing `case_id` = documented seam.
7. **Injectable sessions.** `recentSessions()` is part of `LibraryService` so `-LibraryFixtures` can
   stub history.
8. **Parameterized row.** `LibraryRowView(onTap:, isSelected:)` — phone passes push, iPad passes
   select-on-tap + selected glass fill; no push on iPad.
9. **Grey tokens.** Retired greys approximate the canvas (#D3DAE3/#B9C2CF) via `palette.faint`/
   `hairlineSoft` + opacity — NO hex in screen code (F0 grep rule); approximation documented.
10. **Off-token sizes.** Where a canvas px (8/8.5/9/9.5/11) has no `DSTextStyle`, use
   `Font.archivo(_:weight:)`/`.serifVoice` at the exact px + `.tracking`/`.tabularNumbers()` — don't
   force `.kicker`(10)/`.meta`(11.5).
11. **Ordinal.** Assigned once from the FULL loaded-list descending index (stable across toggles),
   `String(format:"%02d", …)`; >99 cases yield 3 digits (slot widens) — decorative, documented.
12. **Detail layout param.** `CaseDetailContent(layout: .phone/.tablet)`: tablet OMITS the
   "— interviewer side" case-pack suffix + the "It knows." serif aside, uses rating 24 / title 22
   (phone 26 / 24). Parameterized, not hardcoded.
13. **Fixture day-state.** Fixtures use the tablet `CASES` (July-17) snapshot for BOTH phone + tablet
   screenshots — the phone canvas case array lives in the truncated 1-series tail and is unavailable;
   this is screenshot-only DEBUG data, never shipped. Documented deviation from §6's phone=July-16.
