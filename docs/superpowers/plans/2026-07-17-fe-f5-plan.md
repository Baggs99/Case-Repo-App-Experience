## Backend contracts (B3 report — REPORTS OVERRIDE BRIEFS)
- Recap 409: `HTTP 409 {"detail": {"blocked_by_recap": <session_id>}}` on the 5
  candidate seats. Client routes to `.recap(sid)`.
- `GET /api/practice/{id}/negotiation` →
  `{session_id, session_state, your_role, whose_turn('interviewer'|'candidate'|null),
  round_used(0|1|2), current_pick:{case_id,title,case_type,difficulty}|null,
  candidate_counter:{...}|null, candidate_requested_case:{case_id,title,from_role}|null,
  pick_sources?(interviewer-only):{recommended_for_candidate:[{case_id,title,case_type,
  difficulty,why,rule}], interviewer_done_set:[{case_id,title,case_type,difficulty}],
  library_allowed:true}}`. `propose {case_id}` / `accept {case_id}` return the same view
  (accept → updated session row `{...,state:'lobby',case_id}`).
- `POST /swap` → `{swap_invite_id, invitee_id}`. `POST /swap/accept` →
  `{accepted:true, session_id:<new negotiating>, needs_negotiation:true}`.
- `GET /api/v1/recaps` → `{recaps:[{session_id, case_id, case_title, interviewer_name,
  grade, finalized_at, viewed_at}]}` oldest-first.
- `POST /api/practice/{id}/recap/viewed` → `{viewed:true}` (candidate-only, finalized).
- `POST /api/practice/{id}/recap/close` body `{case_rating:1-5 REQUIRED,
  feedback_thumbs:bool|null}` → `{closed:true, gate_cleared:bool}`. 422 if rating
  missing/out-of-range; 409 re-close. **The debrief close-out IS this endpoint.**
- `GET /api/practice/{id}/feedback` (recap report source; finalized-only, 409 else) →
  `{grade:float|null, finalized_at, notes_md, items:[{id,label,dimension,max_points,
  points,note}], reveals, case_id, case_title}`.
- `POST /api/practice/{id}/finalize` response + push `data` gain `next_recommendation`
  (B4 item `{case_id,title,case_type,difficulty,why,rule}` | null) + `prefill_proposal`
  (`{to_user_id, case_id}` | null). Existing keys unchanged.
- `session_update` arrives via existing signaling WS as `SignalMessage.sessionUpdate`
  (signal-only trigger → SessionViewModel re-fetches `sessionDetail`). Negotiation/swap
  broadcasts ride this. NO new WS wire model.
