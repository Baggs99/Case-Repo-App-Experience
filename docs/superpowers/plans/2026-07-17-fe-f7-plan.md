## PINNED backend payloads (bgap-b8-report Interfaces — exact)
```
GET  /api/v1/drills/gauntlet            → Gauntlet {date,setKey,provisional,slots[6],streak,submitted,result?}
                                          slot {slot,drillType,key,prompt,numbers[],choices?}  (answer redacted)
POST /api/v1/drills/gauntlet/attempts   body {answers:[{slot,value?,choiceIndex?,durationMs?}]×6} (same-origin)
                                          → GauntletResult; repeat → 409 {error:"already_submitted",set_key}; 422 malformed
     GauntletResult {score,slotsCorrect,slots,pointsAwarded,dailyPercentile?,group?,schoolPercentile?,
                     vsPeersDelta?,weakSection?,streak,setKey}   group {groupId,name?,rank,points,pointsBehindNext?}
GET  /api/v1/drills/boards?scope=group|school|global|schools
     group   → {scope,group{id,name?}?,entries:[{userId,displayName,photoKey?,points,rank,streak}]}
     school  → {scope,school{schoolId,name,campusCity,avgMemberPercentile,rank}?,yourPercentile?}
     global  → {scope,yourPercentile?}
     schools → {scope,schools:[{schoolId,name,campusCity,avgMemberPercentile,rank}]}
GET  /api/v1/drills/trends               → {daily:[{date,score}](60d),by_type:[{drillType,attempts,correct,accuracy}],weakest?}
```
**Board reality vs canvas (documented deviation, delta §0.2 HONORED):** B8 exposes per-member literal
rank+points ONLY for `group` (the joined cohort). `school`/`global` return YOUR OWN percentile (single value),
NOT a per-member percentile list; `schools` returns the school-vs-school avg-percentile list. So:
- **C-14** (group) → full literal rank+points+streak list + TOP FIVE ADVANCE divider (canvas-exact).
- **WHARTON** (school) → your school card (name · campus city · avg member percentile · rank) + YOUR percentile.
- **GLOBAL** (global) → YOUR percentile only.
- **SCHOOLS** (schools) → full school-vs-school list (rank · school · campus city · avg percentile), yours highlighted.
The canvas WHARTON/GLOBAL per-member lists are aspirational; render what B8 provides + note the follow-up.
Never render a head-count / "of N".
