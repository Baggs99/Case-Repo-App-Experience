## Pinned API shapes (B6 report — REPORTS OVERRIDE BRIEFS; verbatim)
All `/api/v1`, cookie-session auth. Decode via APIClient's `.convertFromSnakeCase`.
- `GET /connections` → `{connections:[{user_id,display_name,photo_url,bio,free_now,swap_invite_pending}]}`
  (accepted only; `free_now` from availability join; `swap_invite_pending` LIVE on this branch —
  B3 merged, EXISTS in `connections.list_accepted`). **This is the source of FREE NOW + the
  swap-invite decoration — NOT the availability endpoint.**
- `GET /groups` → `{groups:[{id,name,school_id,invite_code,role}]}` (role: "admin"|"member").
- `POST /groups {name}` (1–100 chars) → `{id,name,school_id,invite_code,role:"admin"}` (creator=admin).
- `GET /groups/{id}` (member-only; 404 non-member) — EXACT shapes (webapp/routes/groups.py:90-102):
  `{group:{id,name,school_id,invite_code}, members:[{user_id,display_name,photo_url,role}],
  leaderboard:[{user_id,display_name,photo_url,points,rank,streak}]}`. `group` has NO role;
  **`isAdmin` = my `members[]` row's role == "admin"** (VM matches SessionStore.user.id) — deterministic.
- `POST /groups/{id}/transfer {user_id}` (admin-only) → 200; 403 member / 400 self / 404 target-not-member.
- `GET /groups/{id}/progress` (admin-only; 403 member) →
  `{members:[{user_id,display_name,cases_done,mean_grade,drill_attempts_30d,streak}]}`.
- `GET /leaderboards/school` → `{school:{school_id,name,campus_city,avg_member_percentile,rank}|null,
  your_percentile:float|null}`.
