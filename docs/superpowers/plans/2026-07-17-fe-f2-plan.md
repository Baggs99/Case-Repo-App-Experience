## Pinned API shapes (from bgap reports + verified live in code — REPORTS/CODE WIN)
Decoder is `.convertFromSnakeCase`; dates via the APIClient custom ISO8601
strategy. All GETs cookie-authed; POST/DELETE are same-origin from native (no
Origin header — follow the existing `createProposal`/`sendNoContent` pattern).

- `GET /api/v1/dashboard` (additive superset of today's DashboardStats):
  `sessions_finalized:int, streak_weeks:int, next_session:SessionSummary?,
  streak_days:int, drill_done_today:bool, dimension_averages:[…],
  recommendations:[Rec], diagnostic:Diag, timeline:DashTimeline`
  - Rec = `{case_id:int, title:str, case_type:str, difficulty:str, why:str, rule:str}` (key is `title`, never `case_title`)
  - Diag = `{cases_done_60d:int, dimensions:[{dimension:str,avg_score:float,samples:int}], strengths:[…], weaknesses:[…], focus_dimension:str?, trend:{recent_avg:float?,previous_avg:float?,delta:float?,direction:'up'|'down'|'flat'|null}}`
  - DashTimeline = `{tracked_count:int, next_deadline:{firm_id,name,slug,cycle_label,deadline_date:str,days_remaining:int,readiness_tag:str}?}`
- `GET /api/v1/timeline` → `{as_of:str, readiness:{label:'on_track'|'needs_work',ready:bool,focus_dimension:str?,recent_case_count:int,threshold:float,min_cases:int}, firms:[{firm_id:int,name:str,slug:str,status:str,added_at:str?,deadline:{cycle_label,deadline_date:str,region,is_estimate:bool,days_remaining:int,passed:bool}?,readiness_tag:'early'|'on_track'|'focus',prompt:{show:bool}}]}`
- `GET /api/v1/timeline/firms` → `{firms:[{firm_id,name,slug,tracked:bool,next_deadline:<deadline>?}]}`
- `POST /api/v1/timeline/firms` body `{firm_id}` (track, idempotent) · `DELETE /api/v1/timeline/firms/{firm_id}` (204)
- `POST /api/v1/timeline/firms/{firm_id}/result` body `{outcome}`:
  - `offer` → `{outcome,status:'offer',result_recorded_at}`
  - `no_offer` → `{outcome,status:'rejected',reweight:{focus_dimension:str,suggested_drill_type:str,extra_cases:[int]}}`
  - `waiting` → `{outcome,status:'interviewed',snooze_until}`
  - `didnt_interview` → `{outcome,dropped:true}`
- `GET /api/v1/recommendations?exclude=1,2,3` → `{recommendations:[Rec]}` (Swap)
- `GET /api/v1/drills/gauntlet` → `{date,set_key,provisional:bool,slots:[{slot:int,drill_type:str,key:str,prompt:str,numbers:[str],choices:[str]?}],streak:int,submitted:bool,result:GauntletResult?}`
- `GET /api/v1/drills/boards?scope=group` → `{scope:'group',group:{id,name}?,entries:[{user_id:int,display_name:str,photo_key:str?,points:int,rank:int,streak:int}]}` (cohort footer source: your rank = your entry.rank, "of N" = entries.count [sanctioned joined-cohort literal rank], "N behind №K" = points gap to the entry ranked above you)
- `GET /api/v1/sessions?scope=recent` → `{sessions:[SessionSummary]}` (tablet LAST-NIGHT strip: newest finished session with a grade → "{grade} avg vs {other_user}"; **no recap star-rating exists on any GET — omit "recap rated N/5" on live, flag backend follow-up**)
